# La Brasa — Frontend

Frontend React + Vite del sistema de gestión de La Brasa. Ver el [README principal](../README.md) del repositorio para la puesta en marcha completa (backend incluido), variables de entorno y documentación de la API.

## Desarrollo rápido

```bash
npm install
npm run dev
```

Requiere el backend corriendo en `http://localhost:3000` (ver `src/services/api.js`).
